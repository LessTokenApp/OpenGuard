# OpenGuard Hardening

VPN'siz halka açık ağ sertleştirmesi - Windows 11+ için.

## Kurulum

1. \OpenGuard-Baslat.bat\'ı çift tıkla (admin yetkisi gerekli)
2. Menüden seçim yap

## Özellikler (v0.7.0)

- ✅ Hardening aç/kapat
- ✅ Adaptive Firewall (3 seviye: Basic/Moderate/Relaxed)
- ✅ DNS Güvenliği kontrol (DoH tespiti)
- ✅ Ağ izleme
- ✅ Analytics Dashboard (threat timeline, FREE/PRO tiers)
- ✅ Settings yönetimi
- ✅ Process Monitoring (TDD approach)
- ✅ YAML Config Manager
- ✅ HardeningManager PowerShell IPC
- ✅ AnalyticsEngine (JSONL→SQLite, risk scoring)
- ✅ Qt Stylesheet System (dark mode support)
- ✅ Onboarding Wizard (4 screens)
- ✅ Risk Timeline Analytics (threat analysis)

## Menü Seçenekleri

1. Durum Tespiti
2. Hardening'i Aç
3. Hardening'i Kapat
4. Agresif Mod ile Aç
5. Adaptive Firewall
6. DNS Güvenliği
7. Ağ İzleme / Uyarı
8. Kullanım Kılavuzu
9. Ayarlar
10. Analytics Dashboard
11. Çıkış

## Sistemsel Gereksinimler

- Windows 11 Pro / Enterprise
- PowerShell 5.1+
- Administrator privileges

## Telemetri

OpenGuard internet trafığini şifrelemez. Sadece muhtemel saldırı kapsamını küçültür.
